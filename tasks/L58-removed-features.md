# L-58 — قائمة الميزات المحذوفة من DeckOS Core v0.1

## الهدف
إزالة كل ما لا يُبرر وجوده في Core، وتوثيق السبب، وتحديد المرحلة المناسبة له.

---

## التوثيق (المرتبط بـ Gate 3)

- **APK قبل L-51:** ~48MB → **APK بعد L-51:** ~45MB (تقدير، بدون lib/x86)
- **Runtime قبل trim:** ~1.4GB → **الهدف:** ≤900MB بعد `trim-runtime.sh --apply`
- **RAM PSS:** 90MB → الهدف ≤250MB ✅ (مُتحقق)
- **Desktop startup:** <1s ✅
